# Hydrates

Aplicação para acompanhamento da hidratação diária, com registro de consumo, metas, histórico, estatísticas e gamificação.

# Tecnologias

Backend

* Python
* FastAPI
* MySQL
* MySQL Connector/Python

Web

* React
* JavaScript

Mobile

* React Native
* Expo
* JavaScript

# Estrutura do projeto

* web/: aplicação Web.
* mobile/: aplicativo Mobile.
